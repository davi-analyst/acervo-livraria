# acervo-livraria

📚 Sistema de Gerenciamento de Livraria (CRUD)
Projeto prático desenvolvido para consolidar conhecimentos fundamentais de integração entre PHP e bancos de dados relacionais (SQLite), utilizando o padrão PDO para maior segurança.

1. O que é isso?
Uma aplicação web simples de "Livraria" que permite gerenciar um acervo de livros. O sistema realiza as operações básicas de um CRUD (Create, Read, Update, Delete)

Interface simples, assertiva e intuitiva.

Ferramentas: (PHP, SQLite e JavaScript)

Como Usar?

-Clone o repositório para sua pasta local (ex: htdocs no XAMPP).

-Inicie o servidor Apache no seu painel de controle (XAMPP/Wamp/Laragon).

-Acesse no navegador: http://localhost/nome-da-sua-pasta/
